How to use this table

Press Enter to move down a column (Shift+Enter in a task name adds a new line); Enter on the last row adds a new task. Working week, working times and holidays are set under ⚙️ Settings. Click a row to select it for the buttons above, or drag a row by its ID / WBS (⠿) to move it — sub-tasks move with their summary. Durations are in working days (0 = milestone). ID is the task's serial number; WBS shows its outline position (1, 1.1, 1.1.1). Predecessors use the ID with an optional link type and lag, e.g. 3, 3FS+2, 5SS, 6FF-1. Typing a start date pins the task (start no earlier than that date); clear it to unpin. Indent a task under another to make a summary. Float is the number of working days a task can slip without delaying the finish; red rows are on the critical path.

Bid entry

Contract BoQ

This is the BoQ you tendered or quoted, used as the contract for running account bills. Copy it from the project BoQ, or import an Excel file (Ref, Description, Unit, Qty, Rate, with optional Code and Category) from ⋮ menu › Import › Contract BoQ.
